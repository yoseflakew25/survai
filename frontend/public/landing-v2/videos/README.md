# Landing hero videos

Place two muted, loop-friendly clips here (or set env overrides):

| File | Slot |
|------|------|
| `hero-workspace.webm` (+ optional `.mp4`) | Top-right hero cell |
| `hero-lifecycle.webm` (+ optional `.mp4`) | Bottom-left hero cell |

Env:

- `NEXT_PUBLIC_LANDING_HERO_VIDEO_TOP`
- `NEXT_PUBLIC_LANDING_HERO_VIDEO_BOTTOM`

If a file is missing, the cell falls back to the halftone canvas.
